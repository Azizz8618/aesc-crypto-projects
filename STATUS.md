# Статус работ по плану внедрения

Файл отслеживает состояние семи этапов внедрения блочного шифрования
(107 рабочих дней по редакции плана от 12.11.26). Правила ведения:

- статус этапа меняется только по факту, подтверждённому регрессией или
  документом-результатом; критерии приёмки — в
  [docs/stages.md](docs/stages.md);
- галочка ставится в чек-листе только когда работа выполнена и её
  результат воспроизводим в эмуляторе или в документе;
- даты начала и окончания заполняются по мере выполнения; плановая
  трудоёмкость фиксирована планом;
- изменения статуса фиксируются в журнале в конце файла.

Обозначения статусов: `не начат`, `в работе`, `завершён`.

## Этап 1. Проект

Задача: уточнить требования, выбрать точки интеграции, выполнить эскиз
модулей. Результат: решение о составе подсистемы (техническое задание
по ГОСТ 19.201).

- [ ] Уточнены функциональные требования (блок, гаммирование со счётчиком,
      имитовставка, шифрование зон, ключевое хозяйство)
- [ ] Зафиксированы точки интеграции: обработчик ЭК 070, слово паспорта
      задачи, зона ключей вызова 675, персональная библиотека 02570
- [ ] Зафиксированы защищаемые области тома 2053 (зоны 0400–0540,
      0543–0544, 0675, 0300–0377, рабочие зоны; см.
      [docs/plan-overview.md](docs/plan-overview.md), раздел 4.6)
- [ ] Выполнены эскизы модулей: шифр С48, перехват обмена, ключевое
      хозяйство, пользовательская библиотека, расширение dispak
- [ ] Определены границы: что не входит (замена ГОСТ, ДКС/КАДОПАМ,
      остаточные данные)
- [ ] Подготовлено техническое задание по ГОСТ 19.201

## Этап 2. Разработка

Задача: разработать модуль С48 на БЕМШ, библиотеку Паскаля и машинные
процедуры. Результат: объектные модули и библиотеки.

- [ ] Реализован модуль С48 на автокоде БЕМШ: раунд, раскладка
      подключей, узлы замены из слов ключа
- [ ] Разработана библиотека Паскаля: инициализация контекста, блочные
      операции, гаммирование со счётчиком, шифрование файла
- [ ] Разработаны машинные процедуры: перехват ЭК 070, криптосервис
      как задача ОС (зона 675, ЭК 050), проверка ключей
- [ ] Реализованы три системных вызова криптосервиса: шифрование
      области на томе, смена ключа шифра задачи, опрос состояния
      (см. [docs/plan-overview.md](docs/plan-overview.md), раздел 4.5)
- [ ] Реализованы процедуры работы с зашифрованными областями в
      библиотеке 02570: чтение и запись зашифрованной области АРФА,
      смена пароля
- [ ] Реализована имитовставка 24 разряда (нулевой блок, 8 раундов,
      старшая половина)
- [ ] Обеспечено размещение: четыре-шесть зон на модули, библиотека
      02570 рядом с GOSTLIB

## Этап 3. Расширение

Задача: расширить dispak — загрузчик оверлеев и объектный перфоратор.
Результат: прогон статических оверлеев Монитора-80.

- [ ] Реализована выдача объектных модулей перфоратором в файл в
      формате стандартного массива (эталон — эмулятор Дубны)
- [ ] Реализован загрузчик оверлеев: монтирование скомпонованного
      файла оверлея как диска 060, чтение каталога оверлея
- [ ] Статические оверлеи Монитора-80 получены из проекта monitor80-re
- [ ] Прогон статических оверлеев Дубны в расширенном dispak — выдачи
      совпадают с эталоном эмулятора Дубны

## Этап 4. Отладка

Задача: прогоны на эмуляторе, сверка тест-векторов, правка листингов.
Результат: прохождение контрольных примеров.

- [ ] Прогон контрольных векторов GOSTLIB — совпадение полностью
      (см. [docs/stages.md](docs/stages.md), раздел 4)
- [ ] Зафиксированы контрольные векторы шифра С48 после первой сборки
      (далее не изменяются)
- [ ] Цикл «запись зоны — чтение зоны» без расхождений на эмуляторе
      dispak
- [ ] Цикл «пароль — запись — чтение» с базой паролей тома 203
- [ ] Оптимизация по листингам и замерам: зона 1024 слов за десятки
      миллисекунд
- [ ] Негативные случаи: неверный пароль, искажение имитовставки,
      захват занятого тома — обработаны корректно

## Этап 5. Запись

Задача: резервные копии томов, запись модулей в ПЕРСО, контроль
каталогов. Результат: библиотека 02570 с модулем С48.

- [ ] Сняты резервные копии томов, проверены чтением записи обратно
- [ ] Модули записаны в ПЕРСО штатными средствами
- [ ] Контроль каталогов пройден (загрузчик Монитора-80 проверяет даты
      записей)
- [ ] Выполнена побитовая сверка зон после записи

## Этап 6. Испытания

Задача: контрольные примеры задач ОС и пользователя, полная регрессия.
Результат: протокол испытаний (ГОСТ 19.301).

- [ ] Функциональные испытания на dispak: векторы, циклы зон, цикл
      паролей, негативные случаи
- [ ] Регрессия ОС ДИСПАК из исходников re-dispak после включения
      новых модулей
- [ ] Регрессия конвейера документации: 31 случай СИПРОДа, эталоны
      ДРАКОНа
- [ ] Полный пакет испытаний dispak: 51 случай — пройден полностью
- [ ] Проверка на simh с загрузкой ОС с томов (включая конкуренцию
      задач за захват тома)
- [ ] Побайтовая сверка областей тома 2053 до и после включения
      шифрования
- [ ] Имитация отказа ключевого сервиса (негативный случай): служебный
      режим открытого тома (признак в метке) подтверждён
- [ ] Прогон статических оверлеев Дубны в расширенном dispak со сверкой
      выдач с эталоном эмулятора Дубны
- [ ] Критерии приёмки подтверждены: «КОНЕЦ ЗАДАЧИ» без ошибок,
      выдачи совпадают байт в байт, побайтовая сверка томов
- [ ] Оформлен протокол испытаний

## Этап 7. Эксплуатация

Задача: документы ЕСПД, обучение операторов, опытная эксплуатация.
Результат: акт ввода в действие.

- [ ] Выпущены описание применения (ГОСТ 19.502) и руководство
      оператора (ГОСТ 19.503)
- [ ] Выпущены описание программного модуля на БЕМШ и формуляр
      библиотечных процедур
- [ ] Проведено обучение операторов
- [ ] Опытная эксплуатация проведена, замечания сняты
- [ ] Оформлен акт ввода в действие
