# Контроль процессов dispak и simh

Сценарий ищет зависшие процессы эмуляторов и завершает их по cron.
Цели определяются по `comm`: `dispak`, `besm6`, `svs` (последние два —
исполняемые файлы simh в этом окружении).

## Принцип безопасности

1. **Интерактивные процессы не трогаются.** Если у процесса есть
   контролирующий терминал (`tty != 0`), он только пишется в журнал как
   `SKIP interactive`: такой процесс может законно ждать ввода в tmux.
2. **Зомби не убиваются.** Состояние `Z` фиксируется в журнале; такого
   процесса должен подобрать родитель.
3. **Возраст недостаточен сам по себе.** Кандидат на завершение должен быть
   без терминала, старше `--max-age` и не иметь CPU-прогресса дольше
   `--stale`. Долгий прогон с вычислениями не трогается.
4. **Две стадии сигналов.** Сначала `SIGTERM`, затем, если процесс жив
   и прошло `--grace`, `SIGKILL`. Состояние `D` завершается сразу `SIGKILL`.
5. **Проверка перед применением.** `--dry-run` выводит те же решения в
   журнал, но не посылает сигналы.

Пороги по умолчанию: `--max-age 7200` с, `--stale 1800` с, `--grace 300` с.

## Файлы

| Файл | Назначение |
| --- | --- |
| `watchdog.py` | проверка процессов и завершение зависших |
| `crontab.example` | готовое задание cron каждые 5 минут |

## Состояние и журнал

Данные machine-local, в репозиторий не пишутся:

- `~/.local/share/emulator-watchdog/watchdog.log` — решения и сигналы;
- `~/.local/share/emulator-watchdog/state.json` — предыдущие значения CPU-time;
- `~/.local/share/emulator-watchdog/cron.log` — вывод cron.

## Установка cron

```sh
crontab -l > /tmp/cron.bak
cat tools/emulator-watchdog/crontab.example >> /tmp/cron.bak
crontab /tmp/cron.bak
crontab -l | grep emulator-watchdog
```

## Проверка

```sh
python3 tools/emulator-watchdog/watchdog.py --dry-run
tail -20 ~/.local/share/emulator-watchdog/watchdog.log
```

Пример настройки под короткие тесты:

```sh
python3 tools/emulator-watchdog/watchdog.py --dry-run \
    --max-age 300 --stale 60 --grace 30
```

## Ограничения

- Проверка идёт по `comm`, а не по полному пути: если эмулятор запущен под
  другим именем, добавьте его в `TARGETS`.
- Процесс без терминала, который законно ждёт ввода (например, package
  simh без pty), будет признан зависшим после порогов; используйте tmux
  или увеличьте `--max-age`.
- Скрипт не трогает родительские оболочки и tmux-серверы, даже если их
  ребёнок-эмулятор завис.
