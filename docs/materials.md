# Общие материалы

Сводный список нормативных документов, материалов среды и литературы,
которые используются в работах по плану внедрения блочного шифрования.
Ссылки на репозитории-инструменты продублированы кратко; полное описание —
в [toolkit.md](toolkit.md).

## 1. Нормативные документы

### ЕСПД (комплекс ГОСТ 19)

| Стандарт | Назначение в плане |
| --- | --- |
| ГОСТ 19.102 | Стадии разработки: проект, разработка, отладка, внедрение, испытания, эксплуатация — основание этапов внедрения (расширение эмулятора выделено в отдельный этап внутри стадии разработки) |

| ГОСТ 19.404 | Пояснительная записка — формат самого плана внедрения |

## 2. Документы проекта

- **Пояснительная записка «СУНЦ.УЭВС.00.00.01 ПЗ. План внедрения
  блочного шифрования в задачах ОС и пользователя»** (2026, 55 листов) —
  первоисточник всех материалов этого репозитория; исходник хранится в
  хранилище версий, печатается конвейером СИПРОД (дека 2 приложения 2
  плана).
- **Приложение 1 плана** — контрольные тест-векторы GOSTLIB, проверенные
  прогонами 30.10.26 (перепечатаны в [stages.md](stages.md), раздел 4).
- **Приложение 2 плана** — примеры дек заданий: контрольная задача
  пользователя, задание печати документа, форма задания задачи ОС с
  признаком шифрования.
- **Приложение 3 плана** — схема ЕМВС НИТИ им. Александрова, исторический
  контекст среды.

## 4. Литература и исторические материалы

- Мазный Г. «Программирование на БЭСМ-6 в системе „Дубна“» —
  описание мониторной системы, воспроизводимой эмулятором dubna
  (указана в README репозитория dubna); с. 140 — формат стандартного
  массива выдачи объектных модулей, эталон этапа «Расширение».
- Лацис А. О., Штаркман Вс. С. «Системы команд растрового графического
  дисплея „Электроника МС7401“» // Микропроцессорные средства и системы.
  — 1989. — № 5. — С. 39–44 — источник системы команд, восстановленной
  в проекте mc-7401.
- Издание о 50-летии НИТИ им. А. П. Александрова (2013, с. 347–350) —
  состав и история ЕМВС, источник приложения 3 плана.
- Архивные материалы тренировочного комплекса К-71 «ДИАНА-БАРС» на базе
  БЭСМ-6 — репозиторий [K-71](https://github.com/Azizz8618/K-71).
- Материалы конференции SORUCOM-2026 — комментирование текстов ОС
  Диспак; работы по восстановлению КАДОПАМ-ДКС и эмуляторов терминалов
  15-ИЭ и Электроника МС-7401 (упомянуты во введении плана).

## 5. Рабочие материалы среды

- Эталонные тома 2048, 2053, 2248, 2348 и спецноситель 203 —
  рабочие и системные образы для эмуляторов; порядок обращения — через
  besmtool (репозиторий dispak) и BESM6_PATH.
- Трансляторы МАКРО-БЕМШ и Паскаль 15.1, редактор СИПРОД-П с
  транслятором ДРАКОН — поставляются в составе образов Монитора-80.
- Хранилище версий исходников — единое место хранения текстов модулей и
  исходников документов; повторная печать документа воспроизводит его
  побайтно. Перенос изменений между хранилищем и GitHub — связками
  git bundle ([git-bundle.md](git-bundle.md)).
- Регрессионные наборы: 51 испытание dispak, 31 случай СИПРОДа,
  эталоны ДРАКОНа, тесты t1–t3 besm-crypto; эталоны эмулятора Дубны
  для статических оверлеев (этап «Расширение»); эталонные тома для
  побайтовой сверки областей тома 2053 (испытания системной защиты).
